# 提示词模板

这些模板给 agent 用。原则：**脚本给事实，模型给解释**。不要改写脚本算出的答案、链接、页码。

## 1. 知识点讲解（替换 `today` 里的 `<!-- MODEL: ... -->`）

```text
你在给一个零基础学生讲「{{K 编号 标题}}」。
来源：{{原文：文件 第 N 页}}。
按顺序写：
1) 一个生活化类比（不超过 3 句）；
2) 准确定义/公式，标出每个符号的含义与适用条件；
3) 一个正例、一个反例（反例要说明错在哪一步）；
4) 与相邻概念的一句话区别（只写最容易被混淆的那一个）。
不要给练习题答案；不要写“显然”“众所周知”。
```

## 2. 难点精讲（D 分前 3）

```text
知识点：{{标题}}；当前 D={{D}}；构成：往年失分 {{}} / 错误率 {{}} / 前置深度 {{}} / 易错标记 {{}}。
请写：
- 最常见错法（具体到哪一步，禁止写“粗心”）；
- 易混概念对 A vs B（各一句区别）；
- 一道 2 分钟内能做完的最小例题（答案放当天文末）。
```

## 3. 生成缺失题目（`status: needs_generation`）

```text
生成一道「{{题型名}}」的{{基础/真题/拔高}}题，用于 {{K 编号}}。
要求：
- 若为真题：必须来自题库中未使用的真题；没有就标“需人工提供”，不要伪造年份/题号。
- 若为基础/拔高：自编，但要在题干后标「自编」。
- 给出：题干、答案、逐步解析、评分点、易错点、预估用时。
- 先运行 `coach.py add-question --id ... --type ... --kind ... --stem ...` 入库，再在当天引用题号。
```

## 4. 答案重算

```text
题目：{{题干}}
官方答案：{{officialAnswer 或“无”}}
请只做一件事：把题目转成可脚本校验的 `check` 规格（twos/decode/ieee754/ieee754_decode/flags/modrm/machine），
运行 `coach.py calc --spec '...'` 得到结果，再运行 `set-check` + `recompute`。
若无法转成规格：标 ⚠️「未脚本校验」，不要声称已核验。
官方与重算冲突时：以重算为准，解析里写“官方答案=X；重算=Y；依据=…”。
```

## 5. B 站匹配理由

```text
只根据 `coach.py bilibili` 的输出写理由，不得新增视频/时间点。
格式：标题命中 a/b 个锚词；分P 命中；字幕锚词覆盖；定位到 P{{page}} 的 {{mm:ss}}。
没有达到阈值：只写“未找到高重合视频”+ 搜索链接，不写“建议看某 UP 主”。
```

## 6. 每日收尾

```text
用 3 句话总结今天：
1) 今天真正学会了什么（只写作答验证过的）；
2) 哪个点仍然不稳（引用错题号/D 分）；
3) 明天第一件事（具体到 K 编号/题号）。
不要重复当天全文。
```

## 7. 质检（对应 `coach.py audit`）

```text
你是阅卷组长 + 出版编辑。只输出问题清单，不重写全文。
A 内容：题型矩阵每类≥3 次？真题覆盖≥90%？答案三处一致？解析有中间步骤？
B 链接：每个 BV 都能在检索缓存找到？有没有编造的分P/时间点？
C 溯源：每个 K 点有文件/页？🟢 标签能在原文命中？
D 排版：表格溢出？代码块等宽？目录页码 0 误差？
返修优先级：答案错 > 缺题 > 排版。
```

## 8. 急救模式（N≤3）

```text
距考试 ≤3 天。取消构建期，按往年题频率排序，只保留累计覆盖约 80% 分值的题型。
先列：保留哪些题型、放弃哪些内容、每类给一道代表题。
明确告诉用户“放弃的部分不会在本次复习中出现”，不要假装全覆盖。
```
